# Golden Romance — результат локальной реализации

Рабочая ветка: `redesign-november-2026`. PR для проверки изменений: https://github.com/Sodiqov02/Kamoliddin-Parvina/pull/1. Публикация и merge требуют отдельного разрешения.

## Что реализовано

- Конверт из отдельных слоёв: подложка, письмо, боковые сгибы, передний карман, верхний клапан и печать K & P. Открытие занимает 1,3 секунды; reduced motion и ограниченные устройства получают короткий переход. После открытия фокус переходит к именам.
- Восемь смысловых сцен: конверт, имена, фотография, личное приглашение, дата с календарём, свадебный вечер, ресторан, заключение. Обычная прокрутка и ссылки без обязательного snapping.
- Подключена именно предоставленная фотография с сердечным блюром. Исходный WebP сохранён побайтно, без изменения лиц; размер 45 992 байта, соотношение 1100:1021, адаптивная ширина, явные размеры и отложенная загрузка.
- Достоверные данные собраны в `app/wedding.ts`: Kamoliddin и Parvinaxon, 13 ноября 2026, Juma, 18:00, Shabnam toʻyxonasi, Axmedovlar va Normurodovlar oilasi.
- `?guest=` выводится как React-текст. Пустые значения, Unicode, управляющие символы, HTML-подобная строка и длинное неразрывное имя проверены.
- Календарь ноября содержит все 30 дней; 13-е находится в пятничной колонке. Кнопка и число 13 открывают выбор Google Calendar, Apple Calendar (.ics) и Outlook. Файл `.ics` содержит Asia/Tashkent, 18:00, напоминание за день и не содержит выдуманного окончания. Google и Outlook получают часовое техническое окончание с пояснением; напоминание в них настраивается вручную.
- Подготовлено управление необязательной музыкой: без автозапуска, с обработкой ошибки. Пока лицензированного файла нет, управление не показывается. Реальный аудиофайл не проверялся.
- Карта не показывается без подтверждённой ссылки. Для её добавления предусмотрен `wedding.mapUrl`; адрес и координаты не выдуманы.
- Локальные Cormorant Garamond и Manrope с OFL-лицензиями. Новое статическое PNG-превью 1200×630 весит 236 852 байта; прежний динамический OG-маршрут удалён. Метаданные используют цель существующего GitHub Pages workflow; `SITE_URL` позволяет задать иной домен на этапе сборки.

## Дизайн и самооценка

Направление **The name as a monument**, seed **46521085**: два имени становятся подписью разворачивающегося письма, от печати до финального экрана. Живое взаимодействие — открытие персонального приглашения и сохранение реальной даты. Использована одна собственная фотография; стоковых или сгенерированных фотографий и видео нет. Ботаническая веточка нарисована в SVG. Исключения для количества фотографий, бумажной тени, тонкой рамки, подписи над именами и проверки движения без клика описаны в `DESIGN.md`: требования задания имеют приоритет над общими правилами навыка.

## Запуск

```powershell
Set-Location 'Z:\projects\kamoliddin parvina'
cmd /c npm ci
cmd /c npm run build
cmd /c npm run preview
```

Открыть http://127.0.0.1:4173/ или http://127.0.0.1:4173/?guest=Azizbek. Остановка: `Ctrl+C`. После новой сборки обновить страницу `Ctrl+F5`. Если порт занят уже запущенным просмотром, использовать его или остановить прежний процесс.

```powershell
cmd /c npm run lint
cmd /c npm run typecheck
cmd /c npm test
cmd /c npm run test:browser
node scripts/verify-pages.mjs
```

Браузерные проверки требуют установленного Chrome/Edge либо `npx playwright install chromium`. `CHROME_PATH` задаёт другой Chromium. После изменения данных свадьбы пересоздать PNG командой `cmd /c npm run assets:og`, затем собрать проект. Подготовка `npm run pages:prepare` меняет только сгенерированную сборку; для обычного корневого preview выполнить свежий build.

Обновление календаря: `npm run build` автоматически синхронизирует `public/kamoliddin-parvinaxon.ics` с конфигурацией. Проверка меню: `node scripts/verify-calendar.mjs` при работающем preview на порту 4187. Проверены кодирование ссылок, смена часового пояса браузера, клавиатура, Escape и скачивание файла. Ссылки на Google и Outlook проверены с перехватом переходов; фактическое сохранение в аккаунтах и работа в браузерах реальных устройств требуют отдельной проверки.
